# wake-mart

指定した日時に、メッセージ・音・プログラム実行・電源操作を行う常駐アラームです。
**PC がスリープや休止状態に入っていても、時刻になると起こしてから実行します。**

- タスクスケジューラに登録しません
- レジストリに書き込みません（設定は exe の隣の `wake-mart.ini`）
- インストーラーは不要で、`wake-mart.exe` 1 個で動きます（ランタイムも不要）
- Windows 10 / 11 に対応

## 使い方

1. `wake-mart.exe` を好きなフォルダに置いて起動します。
2. 「追加」でアラームを作ります。
3. 閉じるボタンを押してもタスクトレイに残って動き続けます。終了はトレイアイコンを右クリック →「終了」です。
4. 「Windows の起動時に常駐する」にチェックを入れると、スタートアップフォルダにショートカットを作ります
   （レジストリの Run キーは使いません）。

**wake-mart が動いていないとアラームは鳴りません。** 終了するとスリープからも起こさなくなります。

## アラームの設定

| 項目 | 内容 |
|---|---|
| 繰り返し | 1回だけ / 毎日 / 毎週（曜日指定） / 毎月（日付指定。その月にない日は月末） / 一定間隔（○分ごと） |
| 今から○分後に | 「設定」を押すと、1回だけのアラームを今から○分後にします |
| メッセージを表示する | 最前面に窓を出します。「停止」か「スヌーズ」で閉じます |
| 音を鳴らす | 止めるまで繰り返します（最長 10 分）。wav / mp3 / wma などに対応。空欄なら Windows の `Alarm01.wav` |
| プログラムを実行する | exe・bat・ショートカット・文書・URL など。引数と作業フォルダに `%USERPROFILE%` などの環境変数を使えます |
| 終わるまでスリープさせない | 実行したプログラムが終わるまで PC を起こしておき、「最後に」の電源操作は終了後に行います |
| 最後に | スリープ / 休止状態 / シャットダウン / 再起動 / サインアウト / 画面オフ。画面オフ以外は 30 秒前に確認窓が出て、取り消せます |
| スリープ・休止状態から復帰させる | 予定の 30 秒前に PC を起こします |
| 画面を点ける | 鳴ったときに画面を点け、窓を閉じるまで消さないようにします |
| 時刻を過ぎていたら、気づいた時点で実行する | スリープ中などで 3 分以上遅れたときも実行します。オフなら、その回は飛ばします |
| スヌーズ | 鳴った窓の「スヌーズ」で、○分後にもう一度鳴らします |

「テスト」ボタンはその場で鳴らします（電源操作だけは行いません）。

## スリープ・休止状態から起こすには

Windows の電源設定「**スリープ解除タイマーの許可**」が「有効」になっている必要があります。
（コントロール パネル → 電源オプション → プラン設定の変更 → 詳細な電源設定の変更 → スリープ → スリープ解除タイマーの許可）

ノート PC では「バッテリー駆動」側が「無効」になっていることが多く、その場合バッテリーでは起こせません。
今の電源で無効になっていると、wake-mart のメイン画面の下に ⚠ が出ます。

起こせないもの:

- **シャットダウン（電源オフ）からは起こせません。** wake-mart 自体が終了しているためです。
  「高速スタートアップ」付きのシャットダウンも同じです。
- サインインしていない状態では動きません（スタートアップから起動するため）。

## コマンドライン

```
wake-mart.exe                 起動（既に動いていれば、その画面を出す）
wake-mart.exe -tray           画面を出さずにタスクトレイで起動
wake-mart.exe -exit           動いている wake-mart を終了させる
wake-mart.exe -config <ini>   設定ファイルを指定（既定は exe の隣の wake-mart.ini）
```

`-config` で設定ファイルを分けると、別の wake-mart として同時に動かせます。

## ファイル

| ファイル | 内容 |
|---|---|
| `wake-mart.ini` | 設定（UTF-16）。手で書き換えるときは wake-mart を終了してから |
| `wake-mart.log` | 動作の記録（鳴った時刻、スリープ・復帰、画面のオン・オフ、ウェイクタイマーの設定など）。512 KB を超えると `.log.old` に回します |

## ビルド

Visual Studio Build Tools 2022（MSVC）で `build.cmd` を実行します。
アイコンは `tools\make-icon.ps1` で作り直せます。
